## 1. BlenderRAG: 检索增强的 3D 逻辑合成
- **来源**：arXiv cs.HC (2605.00632)
- **链接**：[https://arxiv.org/abs/2605.00632](https://arxiv.org/abs/2605.00632)
- **一句话解释**：通过检索 500 个专家级 Blender 代码示例，让 LLM 能够生成几乎零错误的、可执行的 3D 建模脚本。
- **它为什么重要**：目前 LLM 写 Blender 脚本（BPY）经常幻觉 API。这个项目证明了“代码检索”比“模型规模”更能解决 3D 生成的精确度问题。
- **技术趋势标签**：#Generative3D #Blender #RAG #SpecDriven
- **可复用模式**：**“领域专家代码库 + RAG = 零幻觉工具生成”**。
- **疯狂发明家灵感**：
  1. **一个小实验**：建立一个包含 10 个你最喜欢的 P5.js 或 Three.js 视觉效果的代码片段库，做一个简单的 RAG 助手，尝试用一句话生成复杂的生成艺术。
  2. **一个中型项目**：**“自然语言 Minecraft 建筑师”**。利用相似的 RAG 逻辑，将复杂的 WorldEdit 指令或 Python 建筑脚本向量化，实现“给我建一个哥特式赛博朋克大教堂”。
  3. **一个艺术/游戏/叙事方向**：**“动态场景重塑器”**。在游戏中，玩家的对白会实时触发 Blender 脚本修改场景中的 3D 资产（例如：随着情绪悲伤，周围的建筑开始扭曲或融化）。
- **对我项目的启发**：这正是 Spec-driven development 在 3D 领域的实践。你可以把“设计规范”直接转化为“建模代码”。
- **今天是否值得深入研究**：是
- **建议行动**：做 demo

## 2. Prop-Chromeleon: 变色龙般的生成式触觉道具
- **来源**：arXiv cs.HC (2605.00804)
- **链接**：[https://arxiv.org/abs/2605.00804](https://arxiv.org/abs/2605.00804)
- **一句话解释**：一个 MR 系统，根据用户提示词，利用 AI 动态地将日常物品（如一根木棍）在视觉和逻辑上转化为具有特定触觉反馈的道具（如一把激光剑）。
- **它为什么重要**：它打破了 MR 中“视觉很丰满，手感很骨感”的困境，利用生成式 AI 桥接了物理原型和数字体验。
- **技术趋势标签**：#MixedReality #HCI #GenerativeAI #PhysicalComputing
- **可复用模式**：**“物理载体 + 语义重定义 = 任意道具”**。
- **疯狂发明家灵感**：
  1. **一个小实验**：用手机摄像头识别桌上的杯子，通过 LLM 自动生成一段描述这个杯子在“废土世界”中应该是什么样子的故事和 AR 滤镜。
  2. **一个中型项目**：**“万物皆控制器”**。利用计算视觉和生成式 AI，把任何手边的废料（纸盒、笔筒）一秒变成一个带逻辑的游戏手柄。
  3. **一个艺术/游戏/叙事方向**：**“触觉叙事剧场”**。观众手中拿的是普通的石头，但在 MR 视角下，根据剧情推进，石头会变成心脏、炸弹或金币。
- **对我项目的启发**：非常适合你的艺术技术背景。它启发我们：AI 不仅能生成像素，还能生成“物体的定义”。
- **今天是否值得深入研究**：是（重点看它如何做物理-数字映射）
- **建议行动**：收藏

## 3. Odysseus: 100+ 回合的长程游戏决策 VLM
- **来源**：arXiv cs.LG (2605.00347)
- **链接**：[https://arxiv.org/abs/2605.00347](https://arxiv.org/abs/2605.00347)
- **一句话解释**：通过强化学习扩展视觉语言模型（VLM），使其能在游戏中进行超过 100 轮的复杂长程决策。
- **它为什么重要**：目前的 Agent 容易在长任务中“迷路”。Odysseus 证明了 VLM 可以在没有人类轨迹引导的情况下，通过自我博弈在游戏中进化出长期策略。
- **技术趋势标签**：#VLM #ReinforcementLearning #GameAI #AutonomousAgents
- **可复用模式**：**“视觉观察 -> 长期规划 -> 动作执行”** 的闭环，且具备极长的记忆/规划深度。
- **疯狂发明家灵感**：
  1. **一个小实验**：让 GPT-4o 或 Claude 3.5 玩一个简单的文字解谜游戏，强制它每一步都要回顾之前的 50 步，看它是否能保持逻辑一致。
  2. **一个中型项目**：**“Minecraft 长期生存 Agent”**。不只是挖矿，而是给 Agent 一个“建立一个自动农场”的长程目标，看它如何自主拆解 100 步以上的动作。
  3. **一个艺术/游戏/叙事方向**：**“永恒的 NPC”**。一个在服务器里独自生存、进化并记忆所有玩家行为的 NPC，它的决策跨度长达数周而非数分钟。
- **对我项目的启发**：对于世界生成和游戏系统，长程一致性是“灵魂”。
- **今天是否值得深入研究**：是
- **建议行动**：试用（尝试理解其 Scaling 逻辑）

## 4. PraisonAI: 5 行代码部署 Agent 劳动力
- **来源**：GitHub Trending
- **链接**：[https://github.com/MervinPraison/PraisonAI](https://github.com/MervinPraison/PraisonAI)
- **一句话解释**：一个极简的 Agent 编排框架，只需几行代码就能部署一个包含 RAG、记忆和 100+ LLM 支持的自主 Agent 团队。
- **它为什么重要**：它把复杂的 Agent 工作流抽象成了“劳动力（Workforce）”概念，大大降低了自动化系统的门槛。
- **技术趋势标签**：#AgenticWorkflow #Automation #NoCodeLowCode
- **可复用模式**：**“声明式 Agent 定义”**——你只需描述团队角色，它负责连接。
- **疯狂发明家灵感**：
  1. **一个小实验**：用 5 行代码写一个“艺术评论员团队”，一个负责批判，一个负责夸奖，一个负责写展览介绍。
  2. **一个中型项目**：**“Spec-driven 创意代码生成器”**。输入一个艺术需求，PraisonAI 自动分配一个“架构师 Agent”写伪代码，一个“程序员 Agent”写 P5.js，一个“测试员 Agent”运行并反馈。
  3. **一个艺术/游戏/叙事方向**：**“全自动社交媒体交互艺术”**。部署一群 Agent 模拟不同的艺术流派，在 Twitter 上互相辩论并实时生成作品。
- **对我项目的启发**：极其符合你对“自动化”和“LLM 工具链”的关注，是快速原型化 Agent 系统的利器。
- **今天是否值得深入研究**：是
- **建议行动**：做 demo（今晚的小实验就选它）

## 5. Are You the A-hole? 神经符号伦理推理框架
- **来源**：arXiv cs.HC (2605.00270)
- **链接**：[https://arxiv.org/abs/2605.00270](https://arxiv.org/abs/2605.00270)
- **一句话解释**：利用 MaxSAT（一种逻辑算法）结合神经网络，在高度冲突的道德困境中实现公平、多维度的逻辑推理。
- **它为什么重要**：它不再让 AI 简单地“投票”选出答案，而是用符号逻辑来处理“公说公有理”的冲突。
- **技术趋势标签**：#NeuroSymbolic #Ethics #Reasoning #ConflictResolution
- **可复用模式**：**“LLM 提取论点 + 符号逻辑求解器 = 逻辑一致的结论”**。
- **疯狂发明家灵感**：
  1. **一个小实验**：输入两个完全相反的艺术观点，让 LLM 提取论点，然后用逻辑规则判断哪个论点在逻辑上更自洽。
  2. **一个中型项目**：**“AI 陪审团游戏”**。玩家扮演律师，AI 陪审团不是随机反馈，而是根据你提供的证据进行符号化的逻辑推演。
  3. **一个艺术/游戏/叙事方向**：**“动态道德世界”**。在游戏中，你的每个选择都会被这个框架处理，导致世界观的逻辑规则发生根本性迁移。
- **对我项目的启发**：这为“复杂叙事系统”提供了一个硬核的底层逻辑引擎，不再是随机的对话选择。
- **今天是否值得深入研究**：否（先收藏，作为叙事系统的技术储备）
- **建议行动**：收藏

## 今日模式总结
1. **RAG 正在从“读文档”转向“读代码/读逻辑”**：无论是 BlenderRAG 还是 PraisonAI，核心都是通过高质量的逻辑片段来约束 LLM 的行为。
2. **生成式 HCI 的物理化**：AI 开始被用来重新定义物理世界中的物体属性（Prop-Chromeleon），这为艺术装置提供了巨大空间。
3. **神经符号（Neuro-symbolic）的回归**：纯概率模型在处理伦理和长程规划时乏力，引入硬逻辑（MaxSAT/RL）是必然趋势。

## 今日可做小实验
- **项目名**：**The 5-Line Art Critic Swarm (五行代码艺术评论群落)**
- **输入**：一张你的作品图片（或描述）。

  3. 运行 `praisonai agents.yaml`。
  4. 观察它们如何针对你的“设计规范”进行多维度的互撕。
