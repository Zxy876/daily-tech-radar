## Cactus Needle 3: 8~29MB 极微型结构化输出模型
- 来源：Hacker News / GitHub
- 链接：https://cactuscompute.com/needle
- 一句话解释：不聊天、只干活——把 Function Calling 和结构化 JSON 提取压缩进 8~29MB 的微型专用模型，能跑在手机、单片机甚至可穿戴设备上。
- 它为什么重要：打破了“Agent 必须依赖云端百亿参数大模型”的定势。它不跟你谈天说地，专攻 0 延迟的本地工具调用。这意味着游戏 NPC、物理计算装置终于可以在本地拥有高频、免费、毫秒级的指令决策能力。
- 技术趋势标签：Edge-AI / Local Agent / Micro-Controller / Structured Output / Game Systems
- 可复用模式：**端侧神经反射弧（Reflex Agent Pattern）**——云端慢模型负责宏观叙事与策略，端侧 10MB 微型模型负责高频、确定性的行为解析。
- 疯狂发明家灵感：
  1. **一个小实验**：在本地跑 Needle 3，做一个剪贴板监听脚本：一旦你复制任何混乱文本，毫秒级把它格式化成特定架构的 JSON（0 延迟、0 API 开销）。
  2. **一个中型项目**：**实体交互装置/机械小宠**——在树莓派或微控制器上运行 Needle，通过麦克风或传感器高频生成物理舵机的动作控制协议。
  3. **一个艺术/游戏/叙事方向**：**Minecraft "蜂群" 本地微实体**——大模型负责生成世界大纲，本地用 50 个并发的 Needle 实例分别控制 50 个村民的微观行动逻辑（采矿、逃跑、交易），完全无需担心 API 限流和高昂费用。
- 对我项目的启发：在构建生成式世界或复杂系统时，解耦“高层规划”和“底层行为”。低成本本地模型是做海量自治实体（Autonomous Agents）的核心钥匙。
- 今天是否值得深入研究：是
- 建议行动：做demo

## CUA-S1: 计算机操作的“系统 1（快思考）”专用模型
- 来源：Hacker News
- 链接：https://github.com/trycua/cua
- 一句话解释：将计算机操作分为“慢规划”与“快肌肉记忆”，用轻量级模型专攻 UI 屏幕局部判断与点击定位。
- 它为什么重要：过去让 Claude 3.5/Opus 执行截屏与鼠标点击又贵又慢（系统 2）。CUA-S1 借鉴认知科学的“双系统理论”，把 UI 识别与像素级动作剥离为肌肉级反射，大幅降低交互延迟。
- 技术趋势标签：HCI / Computer Use / Dual-Process AI / UI Automation
- 可复用模式：**双系统交互架构（Dual-System Architecture）**——大模型负责“想做什么”，专用小模型负责“按哪个像素”。
- 疯狂发明家灵感：
  1. **一个小实验**：用 CUA-S1 控制一个无 API 的创意软件（如 Blender、Figma 或纯客户端工具），让它根据自然语言指令自动在界面上寻找菜单项并完成重命名。
  2. **一个中型项目**：**生成式 UI "自动化皮影戏"**——做一个跨软件的 Agent 助手，能在 TouchDesigner 或 Max/MSP 画布上像人类一样快速拖拽连线节点。
  3. **一个艺术/游戏/叙事方向**：**自动游戏盲测员 NPC**：让一个视觉 Agent 扮演不知情的人类玩家，仅通过看游戏画面（无内存 Hook）去玩你做出的解谜游戏 Demo，自动生成交互卡点热力图。
- 对我项目的启发：设计 HCI 工具时，不要总想着把整个屏幕一股脑丢给多模态大模型，用分层思路能做出极其流畅的视觉交互管线。
- 今天是否值得深入研究：是
- 建议行动：试用

## Claude Code 全面支持 AGENTS.md 规范
- 来源：Hacker News
- 链接：https://code.claude.com/docs/en/changelog
- 一句话解释：Claude Code 官方支持读取 `AGENTS.md`，标志着跨工具的 Agent 项目级规范（Spec）正在走向标准化。
- 它为什么重要：过去每个 Agent 工具都有自己的私有配置文件（如 `.cursorrules`、`CLAUDE.md`）。`AGENTS.md` 的通用化意味着 Spec-Driven Development 迎来了跨平台的通用格式。一份规范，多 Agent 共用。
- 技术趋势标签：Spec-Driven Development / Agent Workflow / Standard Protocols
- 可复用模式：**通用规范协议（Universal Spec Context）**——把系统边界、数据模型与协作公理固化在版本控制下的 Markdown 里，作为系统的“机器宪法”。
- 疯狂发明家灵感：
  1. **一个小实验**：在现有个人项目的根目录写一个包含严格交互公理与防御性规则的 `AGENTS.md`，测试不同终端 Agent 对该规范的遵循一致性。
  2. **一个中型项目**：**Spec-Driven Generative World Compiler**：在世界生成项目里写一份 `WORLD_SPEC.md`，Agent 读取该 Spec 自动推导结构树、逻辑规则与自动化单元测试。
  3. **一个艺术/游戏/叙事方向**：**活体设定集（Living Lore Bible）**：把游戏世界观以 `AGENTS.md` 语法组织，让 Agent 充当“世界观审查官”，每次设计新武器或新剧情时，由它自动驳回违反世界观公理的设计。
- 对我项目的启发：强化了“代码只是产物，Spec 才是本质”的思路。未来做项目应优先设计机器可理解的 Spec 架构，而不是直接手写样板代码。
- 今天是否值得深入研究：是
- 建议行动：试用

## BrowserSkill: 寄生于真实已登录浏览器的无感 Agent 接口
- 来源：GitHub Trending
- 链接：https://github.com/Tencent/BrowserSkill
- 一句话解释：通过 CLI + 插件打通本地真实浏览器，让 Agent 随时调用你的已登录环境，且完全不干扰你的当前屏幕操作。
- 它为什么重要：过去做网页 Agent 往往要开一个隔离的无头浏览器（Headless），处理登录态、验证码极度繁琐。BrowserSkill 采取“环境共生”策略，直接借用人类已有的真实会话上下文。
- 技术趋势标签：HCI / Browser Automation / Ambient Computing / Context-Aware
- 可复用模式：**活体上下文注入（Living Session Injection）**——不新建沙盒，直接在人类的生活与工作痕迹中寄生运行。
- 疯狂发明家灵感：
  1. **一个小实验**：写一个终端一键命令，在后台借助你真实登录的 Are.na / Pinterest 账号，无感抓取某个设计主题的最新参考图并存入本地。
  2. **一个中型项目**：**设计资产自动归档器**：当你在 Web 页面（如 Midjourney、Figma）上给资产打上特定星标，后台 Agent 自动抓取元数据、高清图并注入到本地生成式引擎的素材库中。
  3. **一个艺术/游戏/叙事方向**：**侵入式现实游戏（ARG）暗线分发器**：在互动叙事中，让 Agent 悄无声息地在玩家的网页环境里放置“线索碎片”（如一封发往虚构收件箱的邮件）。
- 对我项目的启发：在设计人机协作工作流时，减少“上下文切换”与“冷启动环境配置”能带来无与伦比的交互丝滑感。
- 今天是否值得深入研究：否（原理清晰，适合储备）
- 建议行动：收藏

## 今日模式总结

1. **快慢分层（Dual-System Separation）**：AI 正在从“一个全能大模型包办一切”转向“慢大脑（规划）+ 快肌肉（反射）”。本地十几 MB 的小模型负责毫秒级操作，云端负责深度思考。
2. **规范标准化（Spec-as-Protocol）**：从专有 prompt 走向跨平台的统一规范（如 `AGENTS.md`）。人类的角色愈发变成“系统规则与世界观的 Spec 制定者”。
3. **环境共生（Ambient Co-existence）**：不再强制构建独立的封闭沙盒，Agent 越来越倾向于悄无声息地复用人类现有的应用上下文（已登录会话、本地终端口）。

## 今日可做小实验

### 项目名：LoreKeeper — 基于 AGENTS.md 的游戏世界公理校验器
*用今天标准化的 Spec 思想，做一个 2 小时内可玩的“活体世界观检测机”。*

- **输入**：一段随手写下的新设定文本（例如：`input.md` 写入 "荒原探险家拔出一把通体发着霓虹紫光的等离子激光剑，切开了生锈的黄铜闸门"）。
- **输出**：终端实时输出格式化反馈：
  1. 违背的公理清单（指出哪一条被打破，例如：严禁使用 20 世纪以后的电子/等离子能源）。
  2. 修复建议（改用发光的以太电弧阀）。
  3. 自动生成符合该世界观的道具卡片 JSON。
- **技术栈**：Markdown + 终端 Agent 工具（Claude Code、Gemini CLI，或一个 15 行的 Python 脚本直接调用本地 Ollama / OpenAI API）。
- **第一步怎么做**：
  在一个空目录中新建 `AGENTS.md`，写入以下简短规范：
  ```markdown
  # 世界公理：蒸汽与发条纪元
  1. 动力学铁律：所有能量必须来源于蒸汽、发条弹簧或化学以太，世界上绝对不存在半导体、等离子与现代电力。
  2. 视觉公理：材质必须是黄铜、铸铁、皮革或打磨玻璃。
  3. 你的职责：审讯任何提交的设定文本，严格揪出违背公理的词汇，并强制将其蒸汽朋克化重写。
  ```
  然后运行 CLI 指令或 Python 脚本，观察它是否能把你的随意涂鸦精准规约到 Spec 定义的边界内！
