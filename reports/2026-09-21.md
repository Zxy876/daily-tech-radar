## 今日可做小实验
**项目名：** 终端代码理解助手（Mini Claude Code）
**输入：**
1.  一个 Python 文件（例如：一个你最近写的、有点复杂的函数）。
2.  一个自然语言指令，例如：“解释一下这个函数的作用，并指出其中可能存在的性能瓶颈。”
**输出：**
1.  对该函数功能的自然语言解释。
2.  对潜在性能瓶颈的分析。
**技术栈：**
-   Python
-   `subprocess` 模块
-   一个本地运行的 LLM（例如：LM Studio 提供的 Ollama 或 OpenAI API 的本地模拟）
-   （可选）`tree-sitter` 用于更深入的代码解析。
**第一步怎么做：**
1.  **设置本地 LLM:** 确保你有一个可以本地访问的 LLM 模型，可以通过 `ollama run <model_name>` 或者 OpenAI API 的本地模拟器来运行。
2.  **编写 Python 脚本：**
    *   读取你选择的 Python 文件内容。
    *   构建一个 Prompt，将文件名、文件内容和你的自然语言指令组合起来。
    *   使用 `subprocess` 模块调用你的本地 LLM API（或模拟 API），发送 Prompt 并获取响应。
    *   打印 LLM 的输出。
    *   **进阶：** 如果你想让它更像 Claude Code，可以尝试使用 `tree-sitter` 解析代码，提取函数签名、参数等信息，然后将其作为上下文加入 Prompt。

这个实验将让你直接体验到如何将 LLM 的代码理解能力转化为一个实用的终端工具，为你的 Agentic Workflow 铺路。
