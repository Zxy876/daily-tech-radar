## [1] $8 微控制器上的 28.9M 参数本地 LLM (esp32-ai)
- 来源：Hacker News
- 链接：https://github.com/slvDev/esp32-ai
- 一句话解释：在几块钱的 ESP32 芯片上跑本地小语言模型，彻底脱离网络和云端 API 依赖。
- 它为什么重要：它把 AI 从高功耗 PC 和云端拖入了“物理实体世界”。当计算和推理能在极小、极便宜的物理硬件上离线独立发生时，物理生成艺术、交互装置和离线道具的门槛被彻底打碎了。
- 技术趋势标签：Edge AI, Micro-LLM, Physical Computing, Embedded HCI, Offline Systems
- 可复用模式：**极小边缘模型 + 离线状态机**（在云端训练/裁剪成微型权重，写入物理实体完成离线闭环）。
- 疯狂发明家灵感：
  1. **小实验**：给 ESP32 外接一块 0.96 吋 OLED 屏，做一个“离线赛博算命石头”，手按上去就实时生成一句哲学判词。
  2. **中型项目**：基于 ESP32 的生成式桌面桌游道具——一个离线的实体智能骰子，投掷后根据碰撞姿态和离线小模型，显示一段动态随机生成的遭遇故事。
  3. **艺术/游戏/叙事方向**：**物理 Minecraft 实体红石块**：一个真正的物理方块，把它摆在桌上，内部芯片离线计算并用微型声音/灯光模拟虚拟世界中的能量流转与叙事事件。
- 对我项目的启发：用于探索“离线物理实体 + 极简生成系统”，不要所有 AI 交互都依赖云端 API。
- 今天是否值得深入研究：是
- 建议行动：做demo

## [2] 静默共享登录态的极速 Agent 浏览器 (ego-lite)
- 来源：GitHub Trending
- 链接：https://github.com/citrolabs/ego-lite
- 一句话解释：让 AI Agent（如 Claude Code/Codex）无缝、无感地借用你当前浏览器的已登录状态去跑 Web 自动化，零配置且不抢占屏幕。
- 它为什么重要：以前 Agent 跑 Web 自动化要不被验证码卡死，要不弹出一个新浏览器把用户挤掉。它实现了“环境与上下文的无感借用”，是打造后台隐形 Agent 助手的重要基础设施。
- 技术趋势标签：Agent Browser Automation, Identity Sharing, Ambient HCI, Workflow Integration
- 可复用模式：**无感身份与环境借用（Ambient Session Sharing）**（Agent 共享人类已认证的 Cookie/Storage，在后台暗线执行任务）。
- 疯狂发明家灵感：
  1. **小实验**：写一个后台 Agent，在你逛 ArtStation/Pinterest 时无声观察你的点击，默默爬取视觉元素并自动提取一套 Color Palette 和 Shader 参数文件。
  2. **中型项目**：无感游戏资产处理管道：后台 Agent 监控你的 Web 级设计工具（如 Figma），一旦发现新设计图，悄悄在后台用 Web 工具将其转换成游戏引擎可用的 3D/Sprite 贴图格式。
  3. **艺术/游戏/叙事方向**：**数字影子 NPC**：Agent 在后台借用你的社交或网页历史“静默感知”你最近关注的话题，然后在你的单机游戏或虚拟世界里为你生成一个完全映射你近期精神状态的影子 NPC。
- 对我项目的启发：极大地简化了 Agent Workflow 中处理认证和网页交互的工程复杂度，适合作为后台默默工作的“副驾驶”。
- 今天是否值得深入研究：是

## [3] 基于 Tree-sitter AST 的符号级代码检索 MCP 服务 (jcodemunch-mcp)
- 来源：GitHub Trending
- 链接：https://github.com/jgravelle/jcodemunch-mcp
- 一句话解释：利用 AST（抽象语法树）精准提取 GitHub/代码库中的符号，让 AI 读取代码时节省 95% 以上的 Token。
- 技术趋势标签：Model Context Protocol (MCP), Tree-sitter AST, Precise Context Retrieval, Spec-Driven Engineering
- 它为什么重要：大模型看整个代码文件既贵又容易“幻觉”。用语法树提取精准结构（符号、函数定义、依赖链）喂给 LLM，是 Spec-Driven Development 和 Agent 修改复杂代码的关键一步。
- 可复用模式：**AST 结构化裁剪（Structure-Aware Context Injection）**（不喂长文本代码，只喂抽象语法节点与符号引用关系）。
- 疯狂发明家灵感：
  1. **小实验**：写一个 MCP 插件，让 LLM 只需要读取你的 Creative Coding (p5.js / Three.js) 项目的函数签名 AST，就能精准修改粒子效果而绝不破坏主渲染循环。
  2. **中型项目**：**Spec-Driven 游戏规则重构器**：解析游戏逻辑代码的 AST，当你在 Spec 文档里修改“玩家重力值”或“关卡生成逻辑”时，Agent 能精准找到关联代码节点并做微创手术式的重构。
  3. **艺术/游戏/叙事方向**：**代码透视三维展览**：将复杂代码库的 AST 直接渲染成 Unity 或 Minecraft 里的 3D 建筑树，玩家点击节点时，LLM 现场重构该节点代码并实时将编译结果展示在建筑物墙面上。
- 对我项目的启发：解决 Spec-Driven 框架下 AI 乱改代码、Context Overflow 的致命问题，让大模型只看“骨架”精准操作。
- 今天是否值得深入研究：是
- 建议行动：收藏

## [4] 看板驱动的多 Agent 团队指挥塔 (agent-teams-ai)
- 来源：GitHub Trending
- 链接：https://github.com/777genius/agent-teams-ai
- 一句话解释：用类似 Trello 的看板可视化管理多个 AI Agent 团队，让你像管理公司一样指挥不同模型互相发消息、审查和完成任务。
- 它为什么重要：把复杂的 Multi-Agent 架构从黑盒的代码/终端日志，转变成了极具掌控感和仪式感的“可视化指挥舱”，HCI 交互感极佳。
- 技术趋势标签：Multi-Agent Choreography, Visual Agent HCI, Kanban Workflow
- 可复用模式：**任务状态板作为中央共享状态（Task Board as Central State Engine）**（所有 Agent 不直接乱穿消息，而是围绕看板上的任务卡片状态做流转）。
- 疯狂发明家灵感：
  1. **小实验**：配置一个“三体制作组”（策划 Agent、代码 Agent、美术提示词 Agent），用看板观察他们如何自动接单并协作出一款文字冒险游戏。
  2. **中型项目**：独立游戏制作人 AI 驾舱：将逻辑开发、关卡生成、文案编写映射为看板卡片，让不同的专精 Agent（如 Claude 做逻辑、GPT 做文案）在看板上串行推进。
  3. **艺术/游戏/叙事方向**：**“赛博制作组”模拟经营游戏**：玩家饰演一个游戏项目的制作人（Producer），你的员工全是性格极其古怪的 AI Agent，你需要在看板上分配任务，并调解它们之间关于“设计美学”的吵架。
- 对我项目的启发：启发 Agent Workflow 的界面设计——AI 开发界面不应该只是聊天框，而应该是状态透明的协同指挥舱。

## 今日模式总结

1. **极度精细化的上下文裁剪（Micro-Context & AST Parsing）**
   AI 正在从“暴力塞大上下文”走向“结构化精细提取”。不管是硬件上的 28.9M 微型模型（ESP32），还是软件上的 AST 符号检索（jcodemunch-mcp），**降低无关 Context 噪音**是让生成式系统和自动化变稳定、变便宜的核心。
2. **具象化协同与无感介入（Visual Choreography & Ambient Agents）**
   Agent 的 HCI 正在向两极演进：要么**完全隐藏**在后台共享状态（ego-lite），默默搞定工作；要么**完全可视化**为看板/实体节点（agent-teams-ai），给人类极佳的操控感与仪式感。

## 今日可做小实验

### 🧪 项目名：ESP32-Micro-Poet（微型离线诗意计算盒）
在 2 小时内，把一个 28.9M 的本地小 LLM 刷入几块钱的 ESP32 芯片，做出一个不连网、能从串口接收关键词并实时流式打印诗句的离线物理计算节点。

- **输入**：串口输入的 1 个英文单词（例如 `"rain"` 或 `"cyber"`）
- **输出**：ESP32 在终端/串口监视器中流式吐出由本地小模型生成的 2 行微型意象诗
- **技术栈**：ESP32 开发板 (WROOM/S3)、`esp32-ai` 开源库、`esptool` 烧录工具、Python 串口终端
- **第一步怎么做**：
  1. 克隆项目：`git clone https://github.com/slvDev/esp32-ai.git`
  2. 按照 Readme 步骤，用 `esptool.py` 将官方预先压制好的 28.9M 权重固件一键烧录进你的 ESP32 开发板。
  3. 打开 Serial Monitor（串口监视器），直接敲入一个词，感受离线微型芯片在手心里做 LLM 推理的震撼！
