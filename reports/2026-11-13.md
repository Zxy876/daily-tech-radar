## 今日可做小实验

**项目名：** Agent 寻宝：本地文件扫描器

**目标：** 模仿 AI Agent 发现未标记遗址的思路，让一个简单的 Agent 扫描本地一个指定目录，找出其中“可能隐藏宝藏”（即特定类型的文件或文件夹）的线索。

**输入：**
1.  一个本地目录路径。
2.  一个“宝藏特征”的定义，例如：文件名中包含特定关键词（如 "secret", "hidden", "treasure"），或者文件扩展名（如 ".dat", ".bak"），或者文件夹名称。

**输出：**
一个包含所有符合“宝藏特征”的文件和文件夹列表，以及它们在目录结构中的相对路径。

**技术栈：**
*   Python
*   `os` 模块 (用于文件系统操作)
*   （可选）一个简单的 LLM 包装器，用于解释“宝藏特征”或生成发现报告（但初期可以先用硬编码规则）。

**第一步怎么做：**

1.  **设置环境：** 确保你的 Python 环境已配置好。
2.  **编写核心扫描函数：**
    *   定义一个函数，接收目录路径和宝藏特征（如一个关键词列表、文件扩展名列表）。
    *   使用 `os.walk()` 遍历指定目录下的所有文件和子目录。
    *   对于每个文件，检查其文件名是否包含关键词或其扩展名是否在列表中。
    *   对于每个目录，检查其名称是否包含关键词。
    *   将所有符合条件的路径收集到一个列表中。
3.  **测试：**
    *   创建一个测试目录，里面放一些文件和子文件夹，故意命名一些文件/文件夹，使其符合你定义的“宝藏特征”。
    *   运行你的脚本，传入测试目录和特征，检查输出是否正确。
    *   **初步迭代：** 如果你想让它更“AI”，可以尝试用一个简单的 LLM 来解析用户输入的自然语言“宝藏特征”（例如“我想要找那些看起来像旧数据备份的文件”），然后将其转化为你脚本能理解的规则。

这个实验可以在 1-2 小时内完成，让你体验到 Agent 在数据探索和模式识别方面的基础能力。
