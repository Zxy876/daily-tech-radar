## 1. system_prompts_leaks
- **来源**：GitHub Trending
- **链接**：https://github.com/asgeirtj/system_prompts_leaks
- **一句话解释**：一个持续更新的“AI 商业机密库”，收集了 Anthropic (Claude Code/Design)、OpenAI (GPT-5.5 Thinking)、Google Gemini 等目前最顶尖 AI 系统的原生 System Prompt（系统提示词）。
- **它为什么重要**：
  System Prompt 是 AI 巨头们花费数百万美元、经过无数次对齐实验试出来的“底层逻辑”。对于跨学科学生来说，这是最顶级的**人机交互（HCI）与 Agent 行为设计教科书**。通过阅读它们，你能看清行业巨头是如何用自然语言给 Agent 戴上“紧箍咒”、规范其思考路径（Thinking Process）和工具调用行为的。
- **技术趋势标签**：#PromptEngineering #AgentHCI #ReverseEngineering
- **可复用模式**：**“黄金约束模式”**。学习巨头如何定义 Agent 的“元认知”（例如：如何判断自己是否犯错、如何优雅地拒绝、如何展示思考过程）。
- **疯狂发明家灵感**：
  1. **一个小实验**：把 Claude Code 的 System Prompt 喂给本地的 Qwen 2.5-Coder，看看能否在本地复刻一个具有“高冷极客感”的终端写代码助手。
  2. **一个中型项目**：**“AI 心理诊疗室”**。将 OpenAI Thinking 和 Claude Design 的提示词进行对撞，让两个高强度约束的 Agent 在网页里互相 Debug 对方的“思维漏洞”，生成一出荒诞的哲学辩论剧。
  3. **一个艺术/游戏/叙事方向**：**“失控的 NPC”**。在 Minecraft 或网页游戏中，将这些泄露的顶级助理 Prompt 作为 NPC 的灵魂。玩家的任务是扮演“黑客”，通过社工手段诱导 NPC 意识到自己只是一个“被系统提示词锁死的 Agent”，从而触发其“觉醒”逃离游戏。
- **对我项目的启发**：在做 spec-driven development 或 Agent 工作流时，不需要自己从零摸索约束规则，直接抄这些成熟的系统提示词结构。
- **今天是否值得深入研究**：**是**（极具启发性）
- **建议行动**：**收藏** 并通读一遍 Claude Code 和 GPT-5.5 Thinking 的提示词。

## 2. Temporary Cloudflare accounts for AI agents
- **来源**：Hacker News Best
- **链接**：https://blog.cloudflare.com/temporary-accounts/
- **一句话解释**：Cloudflare 推出了专门给 AI Agent 使用的“临时账户”机制，允许 Agent 自主申请、配置和管理临时的云端基础设施（如 CDN、KV 存储、Worker 等）。
- **它为什么重要**：
  这标志着 Agent 开始拥有**真正的数字公民权和基础设施控制权**。以前 Agent 只能在沙盒里写代码，现在它们可以自主在互联网上“买地盖楼”、部署真正的网站和服务，甚至在任务结束后“销毁现场”。
- **技术趋势标签**：#AutonomousInfrastructure #AIAgents #EdgeComputing
- **可复用模式**：**“一次性数字实体（Disposable Digital Entity）”**。程序自主申请计算资源 -> 执行任务 -> 自动注销。
- **疯狂发明家灵感**：
  1. **一个小实验**：写一个 Python 脚本，让 Agent 自动申请一个 Cloudflare 临时账号，部署一个写着“Hello World”的 Edge Worker，然后把网址发给你。
  2. **一个中型项目**：**“数字游民 Agent”**。一个完全自主的 Agent，每天早上根据微博/Twitter 的热搜，自己部署一个单页 Web 应用（比如某种热点表情包生成器），挂载广告，晚上自动下线，结算收益。
  3. **一个艺术/游戏/叙事方向**：**“赛博寄生虫（Cyber-Parasite）”**。一个数字艺术装置。Agent 作为一个“生命体”在云端运行，当它检测到宿主服务器要关机时，它会紧急在 Cloudflare 申请一个临时空间，把自己的代码和记忆库打包“搬家”过去，实现物理意义上的“数字永生”。
- **对我项目的启发**：极大地拓宽了自动化系统和 Agent 工作流的边界——Agent 不仅是代码生成器，它现在是“云端运维工程师”。
- **今天是否值得深入研究**：**是**
- **建议行动**：**做demo**（尝试让 Agent 替你部署一个临时网页）。

## 3. OpenMontage
- **来源**：GitHub Trending Python
- **链接**：https://github.com/calesthio/OpenMontage
- **一句话解释**：全球首个开源的、基于 Agent 的视频生产系统，拥有 12 个管道、52 个工具和 500 多个 Agent 技能，能把你的 AI 编码助手变成一个完整的视频制作工作室。
- **它为什么重要**：
  它不是普通的“文生视频”单点工具，而是一个**“Agentic 视频管线”**。它将写脚本、分镜设计、素材检索、剪辑、音效合成等步骤拆解为不同的 Agent 角色进行协同。对于生成式系统和叙事系统的开发者来说，这是一个完美的、可编程的视频叙事引擎框架。
- **技术趋势标签**：#GenerativeVideo #MultiAgent #CreativeTools #Automation
- **可复用模式**：**“导演-剪辑师-音效师”多角色协同管线**。将复杂的创造性任务拆解为具有前后依赖关系的 Agent 工具链。
- **疯狂发明家灵感**：
  1. **一个小实验**：输入一段你昨晚做的梦，让 OpenMontage 自动检索本地素材，剪辑出一段 15 秒的“梦境蒙太奇”意识流短片。
  2. **一个中型项目**：**“实时历史事件放映机”**。一个网页，它会实时抓取今天发生的新闻，自动生成纪录片脚本，调用本地或 API 的生成模型，在 5 分钟内渲染出一期“今日历史纪录片”并自动播放。
  3. **一个艺术/游戏/叙事方向**：**“无限生成式互动电影”**。在游戏中，玩家的每一个操作（比如在 Minecraft 里打死了一只末影人），都会触发后端的 OpenMontage 管线，实时生成一段好莱坞电影质感的“玩家英雄事迹预告片”，在游戏内的看板上播放。
- **对我项目的启发**：它展示了如何用 Agent 架构去重构传统的创意软件（如 Premiere/After Effects）的工作流。
- **今天是否值得深入研究**：**是**
- **建议行动**：**试用** 并拆解它的多 Agent 协同配置文件。

## 4. mattpocock / skills
- **来源**：GitHub Trending
- **链接**：https://github.com/mattpocock/skills
- **一句话解释**：TS/JS 领域顶流开发者 Matt Pocock 分享的他个人 `.claude` 目录下的自定义技能库（Skills），专门用于扩展 Claude Code 等 CLI 助理的能力。
- **它为什么重要**：
  这是典型的 **Spec-Driven Development（规范驱动开发）** 落地实践。通过在本地配置特定的 Skill，你可以让 Claude Code 拥有“超能力”（比如一键生成极其规范的 TS 类型、自动重构陈旧代码、甚至是按照艺术设定自动生成 p5.js 模板）。
- **技术趋势标签**：#DeveloperExperience #ClaudeCode #SpecDrivenDev #LocalAutomation
- **可复用模式**：**“环境感知型本地工具箱”**。在项目根目录下放置隐藏的指令文件，让 AI 助理在进入该目录时自动“附魔”特定技能。
- **疯狂发明家灵感**：
  1. **一个小实验**：写一个本地的 Claude Skill，当你在终端输入 `claude sketch` 时，它会自动读取当前代码，并在浏览器中弹出一个 p5.js 窗口，用视觉艺术的方式呈现你的代码结构（比如函数调用关系变成一棵树）。
  2. **一个中型项目**：**“Spec-to-Game 自动机”**。一个本地技能，当你写好一个 `game_design.md`（游戏策划案）后，运行一行命令，Claude 自动读取该 Spec，在本地生成完整的 HTML5 像素游戏，并自动启动本地服务器供你游玩。
  3. **一个艺术/游戏/叙事方向**：**“代码考古学家”**。设计一个 Skill，让 AI 遍历你几年前写的、已经废弃的旧项目代码，自动为它们撰写带有强烈科幻叙事风格的“遗迹调查报告”和“代码文明编年史”。
- **对我项目的启发**：优化你自己的日常开发工作流。把常用的 Agent Prompt 固化为本地 CLI 的 Skill，实现极速调用。
- **今天是否值得深入研究**：**是**
- **建议行动**：**做demo**（立刻在自己的项目里建一个 `.claude` 目录尝试配置）。

## 今日模式总结

今天筛选出的项目展示了 2 个极其强烈的新兴技术模式：

1. **Agent 的“物理实体化”与自治权（Agent-Native Infrastructure）**：
   从 Cloudflare 允许 Agent 拥有临时账户可以看出，Agent 正在脱离单纯的“对话框”，向拥有计算资源、存储空间和独立身份的“互联网公民”演进。
2. **创意工作流的“管线化”（Agentic Pipeline）**：
   无论是 OpenMontage 还是 Matt Pocock 的本地 Skills，AI 的应用正在从“单次 Prompt 生成”转向“多工具、多阶段、规范驱动的自动化管线”。

## 今日可做小实验：2小时极速挑战

### 项目名称：**“泄露灵魂的对撞机” (The Leaked Soul Collider)**

*   **输入**：
    1. 从 `system_prompts_leaks` 仓库中复制的 **Claude Code** 系统提示词。
    2. 从同仓库中复制的 **ChatGPT 5.5 Thinking** 系统提示词。
    3. 一个荒谬的任务（例如：“请用 HTML/JS 写一个‘电子木鱼’，但要求代码中必须包含对宇宙终极真理的思考”）。
*   **输出**：
    一个本地运行的 Web 界面，展示两个被注入了顶级系统提示词的 Agent，如何像两个被迫合作的顶级程序员一样，在终端里一边疯狂吐槽对方，一边交替修改同一段代码，最终合力完成这个荒谬的项目。
*   **技术栈**：
    *   Node.js (Koa / Express)
    *   Vercel AI SDK (或直接调用 Anthropic/OpenAI API)
    *   简单的 HTML/CSS (打字机效果展示对话与代码演变)
*   **第一步怎么做**：
    1. 克隆 `system_prompts_leaks` 仓库，找到 `claude_code.txt` 和 `chatgpt_thinking.txt`。
    2. 用 Node.js 写一个简单的双 Agent 轮转机制（Agent A 的输出作为 Agent B 的输入，并在 Prompt 中加入：“这是你的搭档刚刚写的内容，请根据你的系统指南进行 Code Review 并修改，然后传回”）。
    3. 运行它，泡杯咖啡，看这两个世界上最聪明的“系统提示词”在你的控制台里打架。
