## 1. kajisho5 / ffmpeg-skill
- **来源**：GitHub Trending Python
- **链接**：https://github.com/kajisho5/ffmpeg-skill
- **一句话解释**：把 42 个高阶 FFmpeg 视频处理命令封装成带有机器可读契约的 MCP 服务，让 Claude Code / Cursor 直接化身免配环境的本地视频剪辑师。
- **它为什么重要**：FFmpeg 是参数极度反人类的“瑞士军刀”。该项目证明了：与其指望通用多模态大模型直接生成视频像素，不如让 Agent 通过精准契约控制本地成熟的媒体管线。这是本地创作者工具的新范式。
- **技术趋势标签**：Agent-as-Editor / MCP / Creative Tooling / Local-First
- **可复用模式**：**Contract-first Tool Wrapper**（用机器可读契约与确定性接口，把庞大复杂的旧 CLI 封装为 Agent 可靠操纵的执行单元）。
- **疯狂发明家灵感**：
  1. *一个小实验*：让 Claude 读取一段播客音频的节奏节拍（Onset Detection），自动用此 Skill 切割本地素材，做出 10 秒精准卡点的动态切片。
  2. *一个中型项目*：**Prompt-to-Showreel**：输入 Markdown 剧本和一段几小时的游戏/工作屏幕录制，Agent 自动检测画面动态区域、剪辑关键帧、加动态居中框与字幕，一键导出宣发视频。
  3. *一个艺术/游戏/叙事方向*：**互动叙事流式蒙太奇**：在桌面文字冒险游戏中，后台 Agent 根据当前文本情节的紧张度，实时调度本地视频碎片、叠加老胶片噪点与失真滤镜，作为即时生成的动态背景。
- **对我项目的启发**：Spec-driven 思想不仅适用于写代码，完全可以扩展为“音画剪辑 Spec”——将视频节奏、构图规则写成规范，让 Agent 充当编译为 FFmpeg 的编译器。
- **今天是否值得深入研究**：是
- **建议行动**：试用

## 2. huytieu / COG-second-brain
- **来源**：GitHub Trending Python
- **链接**：https://github.com/huytieu/COG-second-brain
- **一句话解释**：引入工程 V 模型闭环的自进化第二大脑系统，强制遵循“干活的 Agent 绝不给自己打分”，并内嵌了针对产品 UI 的反 AI 塑料感（Anti-slop）设计技能。
- **它为什么重要**：直击当前 Agent 应用的两大顽疾：① 模型自我验证时的幻觉闭环；② 自动化生成的 UI 充斥着千篇一律的渐变紫、毛玻璃与假发光圆圈（AI Slop）。它首次在开源社区将“对抗设计平庸”做成了 Agent Skill。
- **技术趋势标签**：Agent Workflow / Spec-driven QA / Anti-Slop / Multi-agent Verification
- **可复用模式**：**Adversarial Verification & Slop Filtering**（制作与验收解耦 + 显式负向规则过滤生成套路）。
- **疯狂发明家灵感**：
  1. *一个小实验*：为 Cursor/Claude 写一条纯文本的 `anti-slop-ui.md` 规则注入，强制禁止圆角卡片堆叠、居中大标语、紫蓝渐变，测试能否逼模型写出极简黑白高密度界面。
  2. *一个中型项目*：**Dual-Agent UI 编译器**：Agent A 将 Figma 草图或自然语言转化为严格的 DOM 层级与样式 Spec；Agent B 负责编码；Agent C 用 Headless 浏览器无头截图并与设计规范做视觉 Diff，不达标坚决回滚。
  3. *一个艺术/游戏/叙事方向*：**批判性艺术策展对抗体**：一个极端激进的先锋艺术 Agent 负责生成破格设定，另一个学院派 Agent 专挑俗套与陈词滥调并无情报废，在多轮冲突中沉淀高质感架空世界设定。
- **对我项目的启发**：解决 Agent 产出“工业塑料味”的关键不是换更贵的模型，而是在工作流中强行植入“设计审美批判者”的角色和负向约束。
- **今天是否值得深入研究**：是
- **建议行动**：收藏

## 3. WebGL Flight Simulator with seed generated terrain
- **来源**：Hacker News
- **链接**：https://baron.by.dai.studio/
- **一句话解释**：纯前端基于随机数种子（Seed）实时程序化生成三维山脉地貌、极轻量且沉浸感极强的 WebGL 飞行模拟器。
- **它为什么重要**：没有庞大的 3D 资产包，仅靠数学噪声（Noise）、数学种子与 Shader，就在浏览器中榨干了轻量级空间叙事与世界构建的潜力。
- **技术趋势标签**：Procedural Content Generation (PCG) / WebGL / Creative Coding / Seed-based Worlds
- **可复用模式**：**Deterministic Seeded Universe**（通过一个单一数字/字符 Seed，推导整套确定性的地形高程、纹理分布与天气系统）。
- **疯狂发明家灵感**：
  1. *一个小实验*：把这个项目的噪声管线剥离，做一个能根据输入的英文单词 Hash 出不同山峦起伏的 3D 网页卡片。
  2. *一个中型项目*：**文本折叠山谷**：把 LLM 提取的某篇文章的情绪波动曲线（高潮、平缓、急转）映射为地形的起伏参数，让用户开着飞机漫游在一段“文字生成的地貌”之中。
  3. *一个艺术/游戏/叙事方向*：**Minecraft 式低多边形遗迹信使**：玩家驾驶纸飞机在随机种子地形中寻访失落信号，每跨越一个坐标区，背景音轨与地形根据种子算法即时重构。
- **对我项目的启发**：给 LLM 的世界生成寻找载体时，不一定非要接入庞大的 Unreal/Unity，轻量级 WebGL + 确定性数学噪声是做交互原型最自由的试验场。
- **今天是否值得深入研究**：是
- **建议行动**：做demo

## 4. Show HN: The Last Complication

- **链接**：https://lastcomplication.com/
- **一句话解释**：一款致敬 Zachtronics 风格的钟表机械谜题游戏，把齿轮传动、擒纵机构与精密时序拆解为纯粹的系统设计玩具。
- **它为什么重要**：Zachtronics 风格代表了最硬核的“涌现式系统设计（Emergent Systems）”。机械机构本质上就是物理形式的状态机与逻辑门，对可视化编程、游戏系统构建具有极高的人机交互美学价值。
- **技术趋势标签**：Systems-driven Game Design / Mechanical Computing / Visual State Machines
- **可复用模式**：**Physicalized Logic Flow**（把抽象的时间、状态转移、与条件判断，转化为可见的齿轮咬合与机械位移）。
- **疯狂发明家灵感**：
  1. *一个小实验*：用 2D 物理引擎（如 Matter.js）做一个微型发条逻辑门，用物理落球和齿轮转动来计算布尔运算 `AND` 和 `OR`。
  2. *一个中型项目*：**发条时钟式 Agent 执行监视器**：把 Claude/Cursor 执行复杂任务时的 Token 消耗、工具调用序列，投射为一个 3D 机械钟表的游丝摆动与齿轮进退，让“AI 思考过程”具有物理机械的解压美感。
  3. *一个艺术/游戏/叙事方向*：**差分机地下城**：地牢的门禁、陷阱与敌人巡逻路线全由一套可视化的庞大中央齿轮机控制，玩家必须在有限时间内调整传动齿轮比来改变整个房间的重力与机关时序。
- **对我项目的启发**：做 Agent 与复杂系统交互工具（HCI）时，不要老用死板的进度条或树状图；机械咬合与时钟周期这种古老隐喻，能大幅降低用户对黑盒状态的认知焦虑。

## 今日模式总结

1. **底层管线的契约化（Contract-as-Interface）**：开发界不再指望 Agent 凭空顿悟工具，而是用机器可读的结构化契约（如 MCP 视频技能、标准 Skill 描述）去驯服老旧但强大的底层引擎（FFmpeg、本地脚本）。
2. **生成物去平庸化（Anti-Slop by Design）**：AI 辅助设计进入深水区，单纯给 Prompt 无法产出高品味作品。在架构层引入“生成者与裁判解耦”以及“负向设计约束规则”，正在成为高质量创作系统的标配。
3. **物理与数学隐喻（Deterministic Systems & Mechanical Visuals）**：无论基于 Seed 的无限地形生成，还是钟表式的逻辑展开，顶级的交互系统都在利用可解释的数学确定性与具象的机械模型来对抗黑盒 AI 的虚无感。

## 今日可做小实验

### 实验名称：Text-to-Voxel-Island（文本情绪体素浮岛生成器）
- **目标**：2 小时内跑通一个由自然语言驱动种子、并在浏览器内实时生成 3D 旋转体素（Minecraft 风格）浮岛的小原型。
- **输入**：一段情绪提示词（例如："cyberpunk rusted sanctuary" 或 "foggy zen garden"）。
- **输出**：一个 16×16 的可交互 3D 低多边形体素地形块，色彩与地形崎岖度由该提示词决定。
- **技术栈**：单文件 `index.html` + `Three.js` (CDN) + 简易 Perlin Noise 库 + 免费/本地 LLM API（如 OpenRouter/Ollama）。
- **第一步怎么做**：
  1. 新建 `index.html`，引入 Three.js 和一个轻量级噪声库（如 `simplex-noise`）。
  2. 用 LLM 写一段系统 Prompt，要求 LLM 将输入的短语转化为一个 JSON：`{ seed: 42, roughness: 0.8, baseColor: "#2A3439", peakColor: "#E0A96D" }`。
  3. 拿到参数后丢给 Simplex Noise 生成高度图，Three.js 用 `InstancedMesh`（方块）按高度渲染出地形。在浏览器直接点开看效果。
