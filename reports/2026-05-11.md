## 今日可做小实验：**"Spec-Driven 文件整理员"**
**2 小时内可完成。**

- **项目名：** Spec-Sorter
- **输入：** 一个包含杂乱文件的文件夹 + 一个 Markdown 格式的“分类哲学 spec”（例如：“按颜色的心情分类文件，温暖的放一组，寒冷的放一组”）。
- **输出：** 文件夹内的文件被自动重命名并归类到新建的文件夹中。
- **技术栈：** Python + Ollama (Llama 3 / Qwen2.5) + OS library。
- **第一步怎么做：**
  1. 准备一个文件夹，放 10 张不同颜色的图片和 5 个不同主题的文本文件。
  2. 写一个 Python 脚本，列出文件名。
  3. 将文件名列表和你的“分类哲学”发给 LLM，要求它输出一个 JSON：`{"filename": "new_path"}`。
  4. 脚本解析 JSON 并执行 `os.rename()`。

这个实验能让你快速理解 **Spec-driven** 是如何直接干预现实文件系统的。**动手试试？**
