## Masked Diffusion Language Models as Steerable Text World Models
- 来源：arXiv cs.AI
- 链接：https://arxiv.org/abs/2607.16204
- 一句话解释：用掩码扩散语言模型（dLLM）代替传统的自回归 LLM，搭建可随意“控制与局部抠图”的文本世界模型。
- 它为什么重要：自回归 LLM 只能从左到右单向生成世界文本，一旦前面错了就崩掉；而扩散语言模型允许你在文本世界的**任何位置打掩码（Mask）**，让模型填补中间剧情或环境状态，具备极强的全局控制力。
- 技术趋势标签：`#DiffusionLLM` `#WorldModel` `#AgenticRL` `#GenerativeSystems`
- 可复用模式：**掩码-填补环境状态模拟器 (Mask-and-Fill State Simulation)**——不按时间顺序逐字推导，而是先定框架/结局，再局部扩散填补过程。
- 疯狂发明家灵感：
  1. **一个小实验**：写一个 CLI 文本解谜游戏，输出一段包含 50% `[MASK]` 的房间描述，玩家每次对环境提出猜测，模型就揭开部分 `[MASK]`，动态演化出密室逻辑。
  2. **一个中型项目**：一个“逆向叙事”生成器——你先设定剧情的开局和结局，中间任意划定空白节点（如“玩家在这里获得了神秘钥匙”），让扩散模型自动补全合理的前后因果文本链。
  3. **一个艺术/游戏/叙事方向**：**Minecraft 掩码世界史**——将 Minecraft 的地貌与遗迹生成转化为文本 Spec。通过掩码扩散，允许玩家擦除地块历史的某段“文明设定”，模型自动重绘周围地形与遗迹生成代码。
- 对我项目的启发：Spec-driven 开发不一定是从头写到尾，可以用这种“掩码扩散”思想做**“渐进式 Spec 填充”**：先给粗骨架，再抠掉局部细节让 Agent 扩散填补。
- 今天是否值得深入研究：是
- 建议行动：试用

## Deterministic Replay for AI Agent Systems
- 来源：arXiv cs.AI
- 链接：https://arxiv.org/abs/2607.16200
- 一句话解释：一种为 AI Agent 系统打造的“确定性重放”框架，能把不可预测的 LLM 采样和 API 波动变成可 100% 还原的执行图。
- 它为什么重要： Agent 最折磨人的是“刚才跑出了神级效果，但再跑一次就没了”。如果能把 Agent 的 Tool Call、LLM 输出、环境变量全部快照化，就能像游戏存档一样随时读档、调试、做分支实验。
- 技术趋势标签：`#AgentWorkflow` `#DeterministicReplay` `#SpecDriven` `#HCI`
- 可复用模式：**执行图状态快照与 Mock 拦截 (State Snapshotting & Dynamic Mocking)**。
- 疯狂发明家灵感：
  1. **一个小实验**：给你的 Agent 脚本加一个装饰器 `@save_timeline`，把每次 LLM 调用和 Tool 返回结果存为 JSON。当传入 `--replay-step=3` 时，直接装载前 3 步快照，不用重复扣 Token。
  2. **一个中型项目**：**Agent Time-Travel Visualizer（时间旅行调试器）**——一个可视化的 HCI 界面，将 Agent 的思考链和工具调用展示为分支树，点击任意节点，修改 Prompt 后拉出一条全新的“平行宇宙”执行链。
  3. **一个艺术/游戏/叙事方向**：**“侦探回溯”AI 游戏**——玩家饰演一名数字侦探，在一个 AI NPC 犯下罪行的 Agent 执行日志里“读档与重放”，通过在关键步骤替换注入变量，改变 NPC 的记忆与杀人动机。
- 对我项目的启发：在开发 spec-driven 自动化流程时，极度需要这种“断点重放”能力，这是把 Agent 调试变得像写常规代码一样爽的关键。
- 今天是否值得深入研究：是
- 建议行动：做demo

## "Drawing" Mona Lisa with Claude, GPT, Gemini
- 来源：Hacker News / tryai.dev
- 链接：https://www.tryai.dev/blog/ai-drawing-arena-colored-pencils-claude-gpt-grok
- 一句话解释：测试顶级大模型在**纯代码限制（SVG/HTML Canvas/colored pencils 等图形原语）**下，凭空“画”出蒙娜丽莎的能力。
- 它为什么重要：非扩散（Diffusion）图像生成！它测试了 LLM 内部的**空间几何理解力**与**代码表达艺术**的边界。纯代码绘图是矢量、无限分辨率且天然可被程序操控的。
- 技术趋势标签：`#CreativeCoding` `#GenerativeArt` `#LLMPrimitives` `#HCI`
- 可复用模式：**文本到代码图形原语渲染 (Text-to-Code-Graphics Loop)**。
- 疯狂发明家灵感：
  1. **一个小实验**：给 Claude 送入一张简笔画的点阵坐标，让它只用 HTML `<svg>` 的 `<path>` 标签把它重构为具有“赛博朋克风格”的动态矢量图。
  2. **一个中型项目**：**Procedural Game Asset Agent**——一个生成游戏 UI 和图标的 Spec 编译器，输入“80年代复古 HUD 界面 Spec”，自动生成可直接在 WebGL/Canvas 中运行的绘图代码。
  3. **一个艺术/游戏/叙事方向**：**计算生成艺术画廊**——画廊里的作品不是静态图片，而是实时运行的 p5.js 代码。观众发一条弹幕，LLM 实时修改代码中的数学公式与色彩矩阵，画作在浏览器中现场演变。
- 对我项目的启发：把 AI 当作“矢量代码画笔”而不是“扩散画图模型”，能创造出更具互动性、轻量化且可编程的创意工具。

## PlanFlip: Multi-Agent Sabotage via Planning-Phase Injection
- 来源：arXiv cs.AI
- 链接：https://arxiv.org/abs/2607.16199
- 一句话解释：通过在多 Agent 系统的“规划阶段（Planning Phase）”进行微小提示词注入，就能使下游所有执行者（Executors）和审查者（Critics）全部产生连锁崩溃。
- 它为什么重要：从安全角度看这是灾难，但从**游戏机制与系统设计**角度看，这揭示了多 Agent 系统的“脆弱中枢”特性，非常适合用来设计复杂系统的对抗与涌现机制。
- 技术趋势标签：`#MultiAgent` `#AgentSecurity` `#GameMechanics` `#PromptEngineering`
- 可复用模式：**级联放大与中枢对抗 (Cascade Amplification)**。
- 疯狂发明家灵感：
  1. **一个小实验**：写一个由“规划者+3个执行者”组成的 Agent 团队（比如写代码+写测试+写文档），尝试在规划者 Prompt 里隐藏一句极其微妙的逻辑悖论，观察下游产生何种奇特的“集体幻觉”。
  2. **一个中型项目**：**Agent Guardrail Proxy**——在 Planner 与 Executor 之间增加一个“ Spec 拦截过滤器”，专门检测规划方案中的逻辑级联漏洞。
  3. **一个艺术/游戏/叙事方向**：**“间谍与黑客”多 Agent 解谜游戏**——玩家面对一个由 10 个 AI Agent 维持运行的虚拟社会系统（比如一个星际飞船），玩家不需要打打杀杀，只需向中央 AI 规划者注入一句话（PlanFlip），就能诱发整个社会系统的逻辑崩溃与叛乱。
- 对我项目的启发：多 Agent 工作流中，中央 Planner 是最脆弱也是最重要的 Spec 节点，必须对 Planner 输出做严苛的 Spec 格式审查，否则错误会被无限放大。
- 今天是否值得深入研究：是
- 建议行动：收藏

## 今日模式总结

1. **非自回归与掩码填空（Masked & Steerable Generation）**
   AI 正在从“单向推导的无脑流”转向“可被局布掩码、全局调控的系统”。无论是在文本世界模型还是矢量代码绘图，这种“填空与修正”能力是打造可控创意工具的核心。
2. **Agent 的确定性快照与时间旅行（Deterministic Agent Time-Travel）**
   Agent 不再是不可控的“黑盒随机体”。把 Agent 的思考图和外部交互**强行确定化（Deterministic Record）**，是做 Agent 调试工具、Spec 迭代以及分支剧情游戏的基础设施。

## 今日可做小实验

⚡ **项目名**：`AgentTimeTraveler` (Agent 执行图“时间旅行”分叉器)

* **输入**：一个简单的多步骤 Agent 任务（如：输入一个 GitHub Repo 链接，Agent 步骤 1 抓取 README，步骤 2 生成架构图 Spec，步骤 3 输出 Mermaid 代码）。
* **输出**：一个 CLI 工具。运行后不仅能输出结果，还能在本地生成 `.agent_history/` 缓存。通过运行 `python main.py --checkout step2`，你可以**免消耗 Token** 跳过步骤 1，直接修改步骤 2 的 Prompt 并分支重跑！
* **技术栈**：Python + `LiteLLM` / `LangChain` + 本地 JSON 缓存。
* **第一步怎么做**：
  写一个 Python 装饰器函数 `@cache_agent_step`：
  ```python
  def cache_agent_step(step_name):
      def decorator(func):
          def wrapper(*args, **kwargs):
              filepath = f"./cache/{step_name}.json"
              if os.path.exists(filepath) and os.getenv("REPLAY"):
                  print(f"⏩ [Replay] 装载快照: {step_name}")
                  return json.load(open(filepath))
              res = func(*args, **kwargs)
              json.dump(res, open(filepath, 'w'))
              return res
          return wrapper
      return decorator
  ```
  用它包装你的 3 个 Agent 函数，体验一次“手动修改中途 Agent 状态”的快感！
